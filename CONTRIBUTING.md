# Contributing to Riverside

Thank you for contributing to Riverside. Please follow these guidelines:

1. **Fork and branch** — create a feature branch from `main`.
2. **Code style** — follow existing Python style (PEP 8) and project conventions.
3. **Tests** — add or update tests in `tests/` and ensure `pytest` passes locally.
4. **Commits** — use clear, imperative commit messages.
5. **Pull requests** — open a PR against `main` with a description of changes and any relevant issue references.
6. **Review** — be responsive to review feedback and CI results.

By contributing, you agree that your contributions are licensed under the MIT License.
